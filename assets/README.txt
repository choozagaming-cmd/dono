Put your personal Rare Drop files in this folder.

Examples:
  ember-crate.webm
  ember-crate.mp3
  void-core.gif
  void-core.mp3
  crown-drop.webm
  crown-drop.mp3

Then edit config.js, for example:
  assetUrl: "assets/crown-drop.webm",
  soundUrl: "assets/crown-drop.mp3",

Recommended overlay animation format: transparent WebM when your OBS/browser setup supports it.
Keep files reasonably small for fast alert playback.
