# Stream Command Center V8

This version redesigns the streamer side around interactions rather than loose canvas elements.

## Research ideas applied
- DropFlares: each paid interaction feels like a distinct product with obvious stream impact.
- StreamElements: configure alert types/variations and reuse a browser source.
- Ko-fi: keep testing and OBS linking obvious and fast.

## Main workflow
1. Select source profile (1080p / 2K / vertical).
2. Select an interaction card.
3. Pick stream impact (Subtle / Standard / Hype / Takeover).
4. Pick one position and one size.
5. Configure design, media/TTS and rules.
6. Test in OBS, then publish.

## New interaction templates
- Jumpscare
- Sound Bite
- Meme Blast
- Support / TTS
- Challenge
- Rare Drop
- Spin the Wheel
- Custom Reward

## Viewer-value controls
Each interaction now exposes a visible "Viewer gets" summary in Studio and supports:
- impact level
- duration
- TTS/media/sound badges
- optional daily stock
- optional cooldown

The Advanced Canvas still exists for pixel-level changes, but normal setup should no longer require moving individual text elements.
