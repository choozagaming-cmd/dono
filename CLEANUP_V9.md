# V9 cleanup

V9 is a consolidation release. The streamer now has one control surface: `stream-studio.html`.

### Navigation
- Stream Studio: same page
- Interactions: scrolls to interaction library
- Media & TTS: opens the Media & TTS tab in the inspector
- Rules & pricing: opens the Rules tab in the inspector
- Viewer page: opens the public page

There is no separate Dashboard or Advanced Canvas in this build.
